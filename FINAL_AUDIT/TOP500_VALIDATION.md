# top500.csv validation

File: `top500.csv` at the project root. Generated by `python -m models.predict`; never hand-edited.

| Check | Result |
| :-- | :-- |
| Physical lines | 501 (one header + 500 data rows) |
| Header | exactly `cve_id` |
| Columns | exactly one; no index column |
| Data rows | 500 |
| Unique ids | 500 |
| Malformed ids | 0 (`CVE-YYYY-NNNN…` pattern) |
| Membership | every id is in `data/scoreboard_2026.csv` |
| Duplicates | none |
| Ordering | exactly the first 500 rows of `artifacts/ranked_2026.parquet`, descending risk score |
| Source cohort | 2026 predictions, not the historical validation output |
| MD5 | `4677d079b77a6262a70e265cb3136d4e` |
| First id | `CVE-2026-2699` |

These properties are executable:

- `tests/test_pipeline.py::test_top500_format` — one column, 500 unique, subset of scoreboard.
- `tests/test_pipeline.py::test_top500_matches_model_order` — exact order match with the ranked table
  and monotone decreasing risk score.

Independent shell check performed during the audit:

```bash
python - <<'PY'
import pandas as pd
from pathlib import Path
p = Path("top500.csv")
df = pd.read_csv(p)
assert list(df.columns) == ["cve_id"]
assert len(df) == 500 and df.cve_id.is_unique
board = set(pd.read_csv("data/scoreboard_2026.csv", usecols=["cve_id"]).cve_id)
assert set(df.cve_id) <= board
ranked = pd.read_parquet("artifacts/ranked_2026.parquet")
assert df.cve_id.tolist() == ranked.head(500).cve_id.tolist()
print("top500 valid; md5 4677d079b77a6262a70e265cb3136d4e")
PY
```

The original file was not overwritten during validation. A regenerated file must pass the two tests
before it replaces this one.
